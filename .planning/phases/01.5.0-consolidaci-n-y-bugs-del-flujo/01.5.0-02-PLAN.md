<objective>
Eliminar el doble hash MD5 por copia (requisito R4, decisión D-03 de CONTEXT.md): `copy_verified` calcula el hash del origen una sola vez durante el stream-through de copia y lo devuelve, sin volver a leer el destino entero con `calculate_md5`. Misma garantía de integridad, se conserva la semántica de borrado de destino corrupto.

Purpose: Para una tarjeta SD de 128 GB el doble hash duplica el tiempo de lectura del disco destino (Performance Bottleneck de CONCERNS.md). El pase único es la práctica estándar (rsync sin `--checksum`) y no pierde garantía: el destino contiene exactamente los bytes leídos+hasheados.

Output: `ingestor.py` `copy_verified` sin relectura de destino; tests de `test_ingestor.py` reescritos para el nuevo mecanismo.
</objective>
