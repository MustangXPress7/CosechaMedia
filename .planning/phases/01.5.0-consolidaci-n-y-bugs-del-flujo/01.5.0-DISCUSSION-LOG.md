## Fallbacks de metadatos

| Option | Description | Selected |
|--------|-------------|----------|
| Reintento + aviso (Recomendado) | 2º intento con timeout mayor + `-read_intervals` de solo duración; si aun falla, fila marcada "metadatos no verificados" visible | ✓ |
| Fallback mtime+ext | Sin reintento: mtime + extensión, fila "estimado" | |
| Marcar para re-escaneo | Reintento y fila marcada para re-detección manual posterior | |

**User's choice:** Reintento + aviso (Recomendado)
**Notes:** Sin "Unknown" silencioso ni `file_size=0`; la regla "no esconder nada" de la fase 1 aplica al aviso.

## Garantía vs. doble MD5

| Option | Description | Selected |
|--------|-------------|----------|
| Hash único stream (Recomendado) | Hash fuente durante la copia, destino no se relee; misma garantía MD5 | ✓ |
| Tamaño + spot-check | Hash de origen + verificación de tamaño/bloques en destino, más rápido, garantía menor | |
| Doble hash actual | Conservar la doble lectura (verificación completa del destino) | |

**User's choice:** Hash único stream (Recomendado)
**Notes:** Se conserva el borrado de destino corrupto; cambio interno en ingestor/utils.
