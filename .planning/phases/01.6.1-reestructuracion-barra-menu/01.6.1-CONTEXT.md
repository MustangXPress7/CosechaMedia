# Phase 1.6.1: Reestructuración barra de menú – Datos, Utilidades, absorción Ingesta

**Gathered:** 2026-09-08
**Status:** Ready for planning

<domain>
## Phase Boundary

Reestructuración de la barra de menú de CosechaMedia para agrupar acciones por intención del operador:
- Absorber el menú **Ingesta** en **Proyecto** (renombrar Archivo → Proyecto) y mover acciones de configuración de proyecto a ese menú.
- Crear menú **Datos** con acciones destructivas y de mantenimiento agrupadas.
- Renombrar **Herramientas** → **Utilidades** y contener solo "Reorganizar footage…".
- Mover **Idioma** dentro de **Ayuda**.
- Mantener atajos existentes (Ctrl+D) y textos en español con `tr()`.

No se produce refactor del core; los cambios se limitan a `app/ui/mixins/menu_mixin.py` y a strings de traducción si corresponde. No se implementa código en esta fase de planificación.

## Target Structure (Decisiones de usuario)

- Absorber Ingesta en Proyecto:
  - Menú &Archivo → &Proyecto
  - Mover a Proyecto: Seleccionar destino del proyecto… (Ctrl+D mantenido), Auto-detectar unidades extraíbles al inicio, Gestionar destinos de volcado…
  - Mover a Proyecto: acciones de proyecto existentes (Nuevo, Recargar, Eliminar todos, Configuración del proyecto…)
- Nuevo menú **Datos**:
  - Abrir carpeta &datos…
  - Eliminar todos los proyectos…
  - Borrar &dispositivos guardados…
  - Borrar &nombres de dispositivos…
  - Detectar &información de tarjeta SD…
  - Limpiar caché… (acción destructiva/mantenimiento)
- Menú **Utilidades** (renombrado desde Herramientas):
  - Reorganizar &footage…
- Menú **Ayuda** ampliado:
  - Mantener Búsqueda de actualizaciones… y Acerca de…
  - Mover menú Idioma dentro de Ayuda (submenú)
- Menú **Vista** sin cambios
- Menú **Configuración** → evaluar si permanece o se integra en Proyecto (en esta fase se mantiene Configuración para personalización de footage/contenedores)

## Constraints

- Idioma fuente español, todos los strings a través de `tr()` / `self.tr()`.
- No tocar `app/core/` salvo necesidad mínima.
- Mantener tema oscuro/claro y acentos.
- No refactor core; cambios UI únicamente.
- Mantener shortcuts existentes (Ctrl+D, Ctrl+N, Ctrl+Q, F5).
- Acciones destructivas agrupadas bajo Datos con confirmaciones existentes.

## Decisions to Implement

- D-01: Renombrar menú Archivo → Proyecto y absorber ítems de Ingesta relevantes.
- D-02: Crear menú Datos con 6 ítems especificados, agrupando destructivos.
- D-03: Renombrar Herramientas → Utilidades y dejar solo Reorganizar footage.
- D-04: Mover Idioma dentro de Ayuda.
- D-05: Mantener Ctrl+D para Seleccionar destino del proyecto.
- D-06: No eliminar acciones, solo reubicar; conservar wiring existente.

## Implementation Decisions

### D-01 Menú Proyecto
El menú Archivo pasa a llamarse Proyecto y absorbe los ítems de Ingesta relacionados con proyecto: Auto-detectar unidades extraíbles al inicio, Gestionar destinos de volcado… y Seleccionar destino del proyecto… (Ctrl+D). Reversibility: reversible.

### D-02 Menú Datos
Se crea menú Datos con las acciones de mantenimiento/destructivas: Abrir carpeta datos…, Eliminar todos los proyectos…, Borrar dispositivos guardados…, Borrar nombres de dispositivos…, Detectar información de tarjeta SD…, Limpiar caché…. Reversibility: reversible.

### D-03 Menú Utilidades
Herramientas se renombra a Utilidades y queda con Reorganizar footage… únicamente. Si en el futuro se añaden más utilidades, el menú existe como contenedor. Reversibility: reversible.

### D-04 Idioma en Ayuda
El menú Idioma independiente se elimina y se crea como submenú de Ayuda. El wiring de _switch_language se mantiene. Reversibility: reversible.

### D-05 Shortcuts
Ctrl+D se mantiene para Seleccionar destino del proyecto. Ctrl+N, Ctrl+Q, F5 se mantienen. Reversibility: reversible.

</decisions>
