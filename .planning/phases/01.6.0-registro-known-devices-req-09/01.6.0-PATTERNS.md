```python
def _start_work(self, fn, on_done):
    self._cancel_flag = False
    thread = QThread(self)
    worker = _AssistantWorker(fn)
    worker.moveToThread(thread)
    thread.started.connect(worker.run)
    worker.progress.connect(self._on_progress)
    worker.message.connect(self._on_message)
    worker.finished.connect(thread.quit)
    worker.finished.connect(worker.deleteLater)
```

#### Worker signal pattern (selective_dump.py:116-135)

```python
class _AssistantWorker(QObject):
    progress = Signal(int, int)
    message = Signal(str)
    finished = Signal(bool, object)

    def __init__(self, fn, *args, **kwargs):
        super().__init__()
        self._fn = fn
        self._args = args
        self._kwargs = kwargs

    def run(self):
        try:
            result = self._fn(self, *self._args, **self._kwargs)
            self.finished.emit(True, result)
        except Exception as e:
            import traceback
            traceback.print_exc()
            self.finished.emit(False, e)
```

```python
def _unique_dest(dest_dir, src):
    base, ext = os.path.splitext(os.path.basename(src))
    dest_path = os.path.join(dest_dir, os.path.basename(src))
    n = 1
    while os.path.exists(dest_path):

    return dest_path
```

## Anti-Patterns to Avoid (from UI-REVIEW + Research)

1. **SenderEditDialog.exec() in tests:** Hangs offscreen. Always mock with a fake that returns immediately.
2. **_populate_guardados() destroys all selections:** The UI-REVIEW BLOCKER. Split into focused refresh methods; don't rebuild all lists on every browse.
3. **_reset_mtp_thread_local without wait():** Missing `self._stage_thread.wait(2000)` — the COM thread may still hold references.
4. **Inline font-size overrides:** Redundant with QSS template `QDialog QLabel { font-size: 12px }`. Don't add new inline font-size unless different from QSS default.
5. **Hardcoded "Unknown_Camera" strings:** Define `FALLBACK_CAMERA_NAME = "SinClasificar"` in one place, reference everywhere.
