**Bug 1: DB Lock on Duplicate Master Path**
- Al crear un proyecto con una master_path que ya existe en otro proyecto, la DB se bloquea (sqlite3.OperationalError: database is locked) impidiendo crear nuevos proyectos.
- Causa probable: transacción no committeada/cerrada correctamente al detectar duplicado, o lock de escritura retenido.

**Fix en app/core/db.py (create_project ~L400-450):**
1. Verificar duplicado ANTES de abrir transacción de escritura: `SELECT 1 FROM projects WHERE master_path = ?`.
2. Si existe: retornar error controlado (excepción custom `DuplicateMasterPathError` o tuple `(False, "error_msg")`) SIN abrir transacción.
3. Si no existe: abrir transacción, INSERT, commit, close — patrón estándar del proyecto.
4. Asegurar que `get_connection()` usa `check_same_thread=False` y WAL mode (ya está en L26-28).
5. Añadir `conn.execute("PRAGMA busy_timeout = 5000")` tras conectar para esperar locks breves.

**Bug 2: Master Path Not Saved in Wizard**
- Al crear proyecto via ProjectWizard, la master_path seleccionada no se guarda en el proyecto creado.
- Causa: `ProjectWizard.on_finished` no pasa `master_path` a `db.create_project()` o el wizard no la recoge del UI.

**Fix en app/ui/project_wizard.py:**
1. En `__init__` / `_build_ui`: asegurar que el selector de carpeta (QFileDialog.getExistingDirectory) guarda el path en `self._master_path`.
2. En `on_finished` callback (o `accept()`): llamar a `db.create_project(name, master_path=self._master_path, ...)` pasando el path.
3. Verificar que `main_window._on_new_project` / `_create_project_from_wizard` recibe y reenvía correctamente.

**Fix en main_window.py:**
1. En `_create_project_from_wizard` (o donde se maneja `ProjectWizard.finished`): extraer `master_path` del wizard y pasar a `db.create_project()`.
2. Manejar el error `DuplicateMasterPathError` mostrando `QMessageBox.warning` con mensaje claro: "Ya existe un proyecto con esa ruta maestra. Elija otra carpeta."

**Tests:**
- `test_create_project_duplicate_master_path`: crear proyecto A con path X, intentar crear B con path X → error controlado, NO lock, proyecto B no creado.
- `test_wizard_saves_master_path`: completar wizard con master_path Y → proyecto creado con master_path=Y en DB.
- `test_concurrent_create_projects`: simular 2 creaciones simultáneas con paths distintos → ambas OK (WAL mode).
</action>

**Bug: Session Date Interval Not Working**
- El filtro de intervalo de fechas en las sesiones (selector "Últimos X días/semanas/meses") no detecta la unidad correspondiente y no filtra correctamente.

- El spinbox tiene el valor numérico.
- La query SQL debe calcular `date('now', '-N unit')` donde unit = 'day'/'week'/'month'.

3. Construir filtro SQL: `WHERE session_date >= date('now', '-{value} {unit}')`.
4. Ejecutar query y refrescar tabla de sesiones.
5. Verificar que el combo usa `setCurrentIndex` correcto al cargar config guardada (QSettings).

**En db.py (get_sessions ~L479):**
